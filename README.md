# Shohay – Community Service Events

**Live site:** https://your-shohay-site.vercel.app

Shohay (সহায়) connects neighbours with local service drives: winter clothes, blanket distribution, cleanups and more.

## Features
- Browse upcoming service events with search and type filters; past events are hidden automatically
- Create, update and delete your own events, with date and field validation
- Join an event in one click and review everything you joined, sorted by date
- Email/password and Google sign-in via BetterAuth, with JWT-protected API routes
- Light and dark theme toggle, loading skeletons, and a fully responsive layout

## Run locally
```
npm install
.env.local
npm run dev
```
